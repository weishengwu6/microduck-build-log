## 本机结构改进

### 电源支架挖孔避让针脚
改动文件目录：
hardware\mechanical\change\power_support_电源支架-FT_改whj.STEP


- **问题（用户反馈）：** IMU 舵机后方的针脚顶到板件，存在装配干涉。
- **改动（用户确认）：** 对电源支架进行挖孔，为针脚预留避让空间。
- **当前状态：** 已修改模型，**尚未打印验证**；不能据此认定干涉已经消除。
- **待补充：** 修改前后截图、开孔位置与尺寸、修改后模型文件名。

打印后的验证项目：

- [ ] 检查针脚与电源支架的实际间隙，确认装配后不再顶碰。
- [ ] 检查开孔边缘与针脚、板卡及线束的相对位置。
- [ ] 检查开孔后支架的强度、固定效果及装配稳定性。
- [ ] 保存打印参数、装配照片和验证结论。
