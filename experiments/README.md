# 实验索引

用 [实验模板](../docs/templates/experiment.md) 创建 `records/YYYY-MM-DD-topic.md`，分配 `EXP-001` 等唯一编号。当前尚无本机实验结果。

| 编号 | 日期 | 目标 | 配置版本 | 状态 | 记录 / 结果 |
| --- | --- | --- | --- | --- | --- |

## 结果归档

- `records/`：实验设计、环境、操作、原始观测和结论。
- `results/`：适合 Git 管理的小型数据、汇总或大文件索引。
- `../images/demos/`：截图、曲线图和演示封面；完整视频记录外部位置。

命名沿用实验编号，例如 `EXP-001-summary.json`。每个结果说明来源、单位、试次与处理方式；保留失败和中止记录，没有测量的数据不补写数值。

大文件索引至少包含：实验编号、文件名、存储位置、SHA-256、生成配置及访问要求。
